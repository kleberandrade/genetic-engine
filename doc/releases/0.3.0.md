# genetic_engine 0.3.0

## New framework capabilities

- Fixed-count and fractional elite survival policies.
- Elite, linear-rank, truncation and explicit-weight roulette selection.
- Two-point, cycle (CX) and partially mapped (PMX) crossover.
- Insertion, reverse-sequence and partial-shuffle mutation.
- Stateless stopping predicates for generation, fitness, stagnation and elapsed
  time, composed with AND/OR and bounded by the engine's generation cap.
- A runnable travelling salesman example, algorithm catalogue and research
  references mapping the original Dart implementations to their conceptual basis.

GeneticSharp's feature organization inspired the extension boundaries; no code
was copied. This release does not claim feature parity or performance superiority.

## Compatibility and validation

Existing strategy constructors, callbacks, integer elitism, seeded randomness,
legacy stopping priority and immutable parent contracts remain supported.
38 local behavioral tests pass, including deterministic PMX/CX cases, multiset
preservation, invalid boundaries, composable stopping and engine reuse. All four
examples, formatting and static analysis pass. Tagged releases are gated by CI
on Dart 3.3.0 and stable, including publication dry-run.
