# genetic_engine 0.2.1

A pure Dart genetic algorithm framework for Flutter applications and Dart APIs.

## Included

- Typed interfaces for genome creation, fitness evaluation, selection, crossover
  and mutation, plus callback adapters.
- Tournament selection; single-point, uniform and order crossover; bit-flip,
  swap and bounded real-reset mutation.
- Maximization and minimization, elitism, seeded runs, progress reporting,
  target fitness, stagnation and cooperative cancellation.
- Guides under `doc/` for getting started, architecture, extension, integration
  and migration, plus executable examples and contribution templates.

## Validation

19 behavioral tests, static analysis, examples and publication dry-run pass in CI
on the minimum supported SDK (Dart 3.3.0) and the stable SDK.

## Source compatibility

The strategy interfaces replace the pre-release 0.1 function typedefs. Existing
function-based configurations can use `GeneticAlgorithm.withCallbacks`. See
`doc/migration.md` and `CHANGELOG.md`.

## Installation status

This GitHub release distributes source code. Hosted publication on pub.dev is a
separate operation and remains pending until confirmed on the package page.
Use the `v0.2.1` Git tag for source installation in the meantime.
