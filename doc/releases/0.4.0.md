# 0.4.0 — Batch selection and learning examples

Add genuine stochastic universal sampling through the new `BatchSelection<T>`
interface and `GeneticAlgorithm(batchSelection: ...)`. The engine samples a
single parent pool per generation, shuffles a copy and keeps elites separate.
Existing single-parent selectors preserve their on-demand behavior.

Supply exactly one of `selection` and `batchSelection`. The public `selection`
field is now nullable; callers reading it directly need to handle batch engines.
See `doc/migration.md` and `doc/selection.md` for compatibility and pairing rules.

Original eight queens, password and knapsack examples accompany improved README,
architecture and problem-modeling guides. Baker's SUS paper and GeneticSharp's
sample catalogue are acknowledged; no GeneticSharp implementation was copied.

A GitHub source release does not imply hosted publication. Consumer CI remains
pinned to the separately published 0.3.1 until a hosted update is verified.

Validation: 51 local tests passed, analyzer and formatting passed, and all seven
examples executed. [Dart CI](https://github.com/kleberandrade/genetic-engine/actions/runs/43905166657)
passed on Dart 3.3.0 and stable, including publication dry-run.
